# Тема Fluent

`fluent-theme.tar.xz` — собранные темы `Fluent-Dark` (GTK 2/3/4, xfwm4) и набор значков
`Fluent-dark` (с базами `.Fluent-base`, `.Fluent-dark-base` и родительским `Fluent`),
разложенные от корня образа (`usr/share/themes`, `usr/share/icons`).

Исходники, GPL-3.0 (тексты лицензий лежат внутри архива, `COPYING`):
- https://github.com/vinceliuice/Fluent-gtk-theme (ветка master, 03.11.2026),
  `install.sh -t default -c light dark`, стили собраны `sassc`
- https://github.com/vinceliuice/Fluent-icon-theme (ветка master, 03.11.2026),
  `install.sh standard`
